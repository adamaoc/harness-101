# Tutorial

This folder is the static HTML tutorial for Harness 101.

Open `index.html` in your browser to start. Phase 00 lives on the index page, and the build phases continue in `phase-1.html` through `phase-8.html`.

You will build your own TypeScript project named `my-ts-agent` as you follow along. The finished reference implementation lives in `../the-harness/` if you want to compare against a working copy.

The tutorial uses CDN-loaded Tailwind, Prism, and fonts, so open it on a machine with network access for the page styling and code highlighting to load.
