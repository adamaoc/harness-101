About this project

Most guides explain agents at a high level: “give the model tools and let it loop.” That is true, but it skips the part that actually matters — how you wire memory, tools, permissions, and logging so the system stays predictable.

This tutorial is the lesson. You create your own project folder (we use my-ts-agent in the examples) and add one file at a time starting with Phase 00 on this page, then Phases 01–08 in their own files. The repo also includes a finished reference copy in the-harness/ if you want to compare or run something working while you learn — but the goal is that you build it.

No web app, no framework magic — just Node, TypeScript, the OpenAI SDK pointed at xAI’s API, and a REPL-style loop you control. When something breaks, you will know which file to open.

Full feature set (when you finish all phases)

Early phases build the core loop; later phases add the patterns you see in serious coding agents. When you are done, your harness includes:

  • Durable sessions — conversation history saved as JSONL on disk; survives restarts
  • Grok client — thin wrapper around the OpenAI SDK at api.x.ai
  • Filesystem tools — list_files, read_file, write_file (workspace sandboxed to your project root)
  • Agent loop — model → tool calls → tool results → repeat until the turn finishes (up to 25 steps per prompt)
  • Turn snapshots — hidden system records per loop step for debugging what the harness knew at each moment
  • Three profiles — Planner, Implementer, and Reviewer with separate prompts and tool allow-lists
  • Structured logging — harness events in logs/*.jsonl (tokens, tools, errors, compaction)
  • Diffs on write — unified diff in every write_file result so you see what changed
  • Context compaction — summarize and hide older messages when the thread gets long
  • Sub-agents — delegate spawns a short-lived planner or reviewer in a child session
  • Terminal CLI — interactive prompts; empty line to quit

Phase 08 also points at sensible next steps (approval flows, tests, git checkpoints, and more) without cramming everything into one lesson.

Mindset & Core Concepts

Before we write any code, we need to understand what we're actually building.

The Most Important Idea

The model (Grok, Claude, GPT, etc.) is just the brain.

The harness is the body — it gives the brain hands (tools), memory (session history), safety brakes (permissions), and eyes (logging & context).
